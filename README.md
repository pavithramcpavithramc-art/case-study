Pavithra C — Portfolio

This repository contains a minimal, production-quality portfolio site built with HTML5, CSS3, Tailwind CSS (CDN), and vanilla JavaScript (ES6 modules).

Structure:
- index.html — Home and overview
- work/ — Case study page for SpendWise
- css/styles.css — Small custom styles and accessibility helpers
- js/ — Modular JavaScript (navigation, animations, projects, main)
- assets/images — SVG placeholders for portrait and project preview

Notes:
- Tailwind used via CDN for simplicity. For production, consider a build step to purge unused CSS.
- SpendWise includes a small localStorage-backed demo to show front-end skills.
- The site focuses on accessibility, responsive design, and minimal, editorial visuals.
